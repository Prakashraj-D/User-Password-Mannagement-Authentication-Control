# 🔐 User Password Management & SSH Key Authentication Control – Red Hat Linux

## 📘 Project Overview
This project is a Linux-based **user management and authentication control system** built using **Bash scripting** on **Red Hat Linux**. The core objective is to automate user administration with secure **SSH key-based authentication**, enhancing security and efficiency in system access control.

---

## 💡 Features

- ✅ Add New Linux Users  
- 🔐 Set or Change User Passwords  
- 🔑 Generate & Configure SSH Key for Secure Login  
- 🔒 Lock or 🔓 Unlock User Accounts  
- 📄 View Authentication Logs (from `/var/log/secure`)  
- 🧩 Menu-Driven CLI Interface for Easy Use

---

## 🛠️ Technologies Used

- **Operating System:** Red Hat Linux / RHEL-based distros  
- **Script Language:** Bash (Shell Scripting)  
- **Authentication:** OpenSSH – RSA 2048-bit Key Pair  
- **User Logs:** Secure log monitoring (`/var/log/secure`)

---

## 📂 How to Use

1. Clone or download the project folder.
2. Open terminal and run the script as **root**:
   ```bash
   sudo bash user.sh
   ```
3. Follow the on-screen menu to:
   - Add users
   - Manage passwords
   - Generate SSH keys
   - View logs and manage account status
